# DART-2.4 Changelog

## DART-2.4

- Added explicit causal slot-necessity measurement across source-task pairs.
- Added per-slot causal scores to experiment JSON.
- Added slot-causal threshold to candidate eligibility.
- Kept random-placement, operator permutation, separate-graph, and MLP controls.
- Added live terminal progress bar with seed, candidate count, phase, and percentage.
- Changed result filename default to `dart024_results.json`.
- Preserved DART-2.3 interleaved shared/task architecture as the experimental baseline.
