# DART-3.4 Theory

Core hypothesis:

A task-level program should remain valid across many independently generated distributions of the same task law.

Discovery regimes:
A, B, C, D

Final unseen regime:
E

Selection uses A-D only. E is never used for program selection. Metrics include minimum regime accuracy, cross-regime invariance, necessity, teacher-counterfactual fidelity, program complexity, and final E transfer.
