# DART-3.5

Invariant task-law induction + law-to-program compilation.

DART-3.4 showed that a program can remain accurate across A-D while failing on an unseen E regime. DART-3.5 first infers an explicit structured task law from cross-regime behavioral probes, then compiles that law into a small program around a frozen primitive. Final regime E remains untouched during selection.
