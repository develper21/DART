# DART-2.6 Changelog

## DART-2.6
- Replaced slot reconstruction as the primary causal criterion with minimal causal mediation.
- Added logit-level teacher-aligned intervention trajectories.
- Added necessity, sufficiency, minimality, and Causal Mediation Efficiency metrics.
- Added configurable intervention strength grid.
- Added strict mediation eligibility gates.
- Preserved shared/separate, random placement, permutation, and MLP controls.
- Preserved live terminal progress reporting.
- Fixed minimal-alpha accounting so inactive slots are excluded from the active-slot average.
