# DART-3.9 Theory

The current DART claim must generalize beyond a single holdout.

For each hidden task:
    task -> invariant law -> exact verified program

Proof coverage includes symbolic probes, six independent regimes A-F, and randomized probes. The final E/F regimes are never used to choose among candidates; they are verification-only.

Hidden failures are first-class data:
- no exact program exists in the current language
- law instability
- regime-specific semantic failure
- randomized failure
- seed/program instability
