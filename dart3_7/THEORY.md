# DART-3.7 Theory

A semantic law should be more than a good neural fit. It should compile to a deterministic computation that agrees with the exact task oracle on broad unseen inputs.

Metrics:
- semantic law fidelity
- exact semantic agreement
- symbolic identity battery
- wrong-law / random-law exact controls
- frozen-primitive neural diagnostic
- wrong-primitive neural control

Teacher accuracy is explicitly diagnostic, not the definition of correctness.
