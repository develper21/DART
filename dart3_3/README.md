# DART-3.3

Cross-distribution task-program invariance.

DART-3.2 showed that a task program can achieve high validation accuracy and causal-looking effects yet collapse on the untouched test distribution. DART-3.3 therefore selects programs using two independent target regimes and measures stability of accuracy, necessity, and teacher-counterfactual fidelity across them.

Final test uses a third independently generated target regime (C) and is untouched during selection.
